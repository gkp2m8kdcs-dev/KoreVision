02 · The catalog

Twenty-four numbers, one tap away.

Each calculator accepts physics-realistic defaults so it is useful straight after install, and offers adaptive, scientific, fixed or logarithmic number formatting.

Interfacial

  • Reynolds — Re = ρUL/μ
  • Eötvös — Eo = Δρgd²/σ
  • Morton — Mo = gμ⁴Δρ / (ρ²σ³)
  • Weber — We = ρU²L/σ
  • Froude — Fr = U / √(gL)
  • Ohnesorge — Oh = μ / √(ρσL)

Capillary & Multiphase

  • Capillary — Ca = μU/σ
  • Bond — Bo = ΔρgL²/σ
  • Gas/Liquid flow ratio
  • Void fraction — α = Ag/At
  • Slip ratio
  • Particle Reynolds

Thermal

  • Nusselt — Nu = hL/k
  • Prandtl — Pr = μcp/k
  • Grashof — Gr = gβΔTL³ρ²/μ²
  • Peclet — Pe = ρcpUL/k
  • Biot — Bi = hL/k
  • Fourier — Fo = αt/L²

Transport & Mixing

  • Rayleigh — Ra = gβΔTL³ / (μα)
  • Damköhler — Da = kτ
  • Kirpichev — Ki = hμcp/(kΔT)
  • Jacob — Ja = cp,lΔT/hfg
  • Stokes — Stk = ρpdp²U / (18μL)
  • Power — Po = P / (ρn³D⁵)
03 · Flow regimes

Six regimes, one map.

Each dimensionless number is annotated with the regimes it informs. The regime map and 3D studio visualise how they overlap.

Bubbly

Discrete bubbles dispersed in continuous liquid. Eötvös ≲ 1, low gas superficial velocity.

Slug

Large bullet-shaped Taylor bubbles alternating with liquid slugs — typical of pipeline flows.

Churn

Unstable oscillatory flow with high interfacial agitation; transitional between slug and annular.

Annular

Liquid film on the wall, gas core in the centre. High momentum, high Weber.

Mist

Entrained droplets carried by a high-velocity gas stream. We >> Wecrit.

Dispersed

Fine droplets or particles dispersed uniformly in the carrier phase.

04 · Privacy by default

KoreVision is engineered to collect nothing. There are no analytics SDKs, no advertising identifiers, no crash-reporting beacons, no remote configuration calls.
